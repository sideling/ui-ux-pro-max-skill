# Seedance2 Prompt Templates

Ready-to-use prompt formulas combining shot type + movement + transition + style.

---

## Prompt Anatomy

```
[Shot type], [subject + action], [camera movement], [lighting], [mood/style], [technical quality]
```

---

## By Genre

### Cinematic Drama
```
Medium close-up of [character] [action], slow dolly in, shallow depth of field,
soft natural window light, emotional weight, cinematic color grade, 4K
```

### Action / Thriller
```
Low angle wide shot of [subject], handheld tracking forward, harsh contrast lighting,
fast pace, smash cut energy, gritty color grade
```

### Epic / Fantasy
```
Extreme wide shot establishing [location], slow crane rising, golden hour light,
sweeping orchestral feel, cinematic anamorphic lens flare, IMAX quality
```

### Horror / Suspense
```
Dutch angle medium shot of [character], slow push in, low-key side lighting,
deep shadows, creeping dread atmosphere, desaturated cold tones
```

### Music Video
```
Arc shot orbiting [subject], cuts to beat, vibrant neon lighting,
high energy, graphic match cuts between scenes, stylized color
```

### Documentary
```
Eye level medium shot, handheld vérité style, available natural light,
authentic candid feel, observational pacing, natural color grade
```

### Product / Commercial
```
Extreme close-up detail of [product], slow rack focus, studio lighting,
clean white background, smooth gimbal move, premium quality feel
```

---

## Movement Combinations (Power Combos)

| Effect | Formula |
|--------|---------|
| **Building tension** | Static wide → slow dolly in → extreme close-up |
| **Grand reveal** | Low angle → crane up → aerial pullback |
| **Intimacy** | Over-shoulder → match cut → close-up with rack focus |
| **Disorientation** | Dutch angle + handheld + jump cuts |
| **Epic scale** | EWS aerial → tracking shot → medium shot |
| **Time passage** | Dissolve series + slow zooms + Ken Burns |

---

## Transition Sequences

### Emotional Scene Change
```
L-cut: [Scene A dialogue continues] → [Scene B visual begins] → cross-dissolve
```

### Action-to-Action
```
Action cut mid-movement → match cut on form → straight cut continuation
```

### Time Jump
```
Freeze frame → fade to black → fade in new scene with color grade shift
```
